This project you can train the custom gestures you want with your hand from scratch prepare your own dataset train the model and then get the agent in your control ....

the gesture code is in the autodatman file where you set the gestures variable this is the main one to control the training ..

Instructions: 1: To save new data run : py -3.10 auto_dataman.py 2: To train the model run : py -3.10 model.py 3: To test the model run : py -3.10 tester.py
